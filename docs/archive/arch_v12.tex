\begin{abstract}
\noindent This is the \emph{architecture and representation} reference for the v12 stack: what the
policy sees (observation encoding), how it processes it (the two interchangeable trunks), and what it
emits (the gated-allocation action and its distributions). Every number here is read directly from
the package modules \cd{constants.py}, \cd{config.py}, \cd{env.py}, \cd{policy.py}, and
\cd{distributions.py}, and parameter counts are taken from instantiated nets. It documents only what
is wired and operational. The separate document \cd{grpo_v12.tex} covers the critic-free RL
\emph{update} and a family of variance-reduction tricks --- many of which are experimental or have
been ruled out --- and should \emph{not} be read as a description of the shipped architecture.
\end{abstract}

\section{Observation encoding (\texttt{env\_encode})}
All features are computed \emph{ego-relative} (relative to the acting seat \cd{ego}), so the same
network plays any seat. Ownership is a \textbf{4-channel ego-relative seat one-hot} (v9): for body $b$
with owner $o$, channel $r=(o-\text{ego})\bmod n_{\text{players}}$ fires; neutral bodies are all-zero.
Channel 0 is always ``me''; in 2p only channels 0--1 ever fire, so 4p reuses the identical input
space.

\subsection{Per-planet body features (14)}
\begin{center}
\begin{tabular}{@{}clL{0.56\linewidth}@{}}
\toprule
idx & expr & meaning (normalization) \\
\midrule
0  & \cd{p_x / BOARD_SIZE}        & x position $\in[0,1]$ \\
1  & \cd{p_y / BOARD_SIZE}        & y position $\in[0,1]$ \\
2  & \cd{vmag / THREAT_MAX_SPEED} & orbital tangential speed $|\omega|\cdot d$ if rotating, else 0 (\,/6) \\
3  & \cd{cw}                      & rotation sense: $+1$ CCW, $-1$ CW, $0$ if static/comet \\

\subsection{Per-planet threat features (180 $=6\times30$)}
For each planet slot, among all in-flight fleets \emph{currently targeting it} (analytic aim from
\cd{fleet_target_batch}), select the \cd{N_SOON}$=15$ smallest-ETA fleets and the \cd{N_BIG}$=15$
largest fleets (size key $|\text{ships}|\cdot2^{20}-\text{seq}$ for a stable tie-break), giving up to
30 inbound-fleet descriptors; missing slots are zero-padded. Each descriptor is 6 features:
\begin{itemize}
  \item \textbf{owner one-hot (4)} --- an ego-relative seat one-hot of the fleet's owner,
        $\text{rel}=(\cd{f_owner}-\text{ego})\bmod n_{\text{players}}$: channel 0 = self, channels
        1--3 = the opponents in seat order (empty slots all-zero). Mirrors the body ownership
        one-hot, so the policy can tell \emph{which} opponent launched an incoming fleet.
  \item \cd{etf} --- $\text{ETA}/\cd{THREAT_ETA_SCALE}$ (\,/100);
  \item \cd{slg} --- $\cd{ship_log_t}(|\text{ships}|)$, log-compressed fleet size.
\end{itemize}
Stacked as $6\times 30 = 180$. Final $\cd{entities}=[\text{body}\,\Vert\,\text{threat}]$ is
multiplied by \cd{p_alive} so dead slots are 0.

\paragraph{v12 change (per-opponent threat identity).} Before v12 the owner was a single
\emph{sign} ($+1$ self / $-1$ any-opponent), so in 4p all three opponents collapsed into one value
and the policy could not attribute an incoming fleet to a specific rival. The 4-channel one-hot
fixes this (2p still only ever lights channels 0--1, so the 2p input is unchanged in meaning); it
raises \cd{F_DIM} from 104 to 194. Members trained on the old 104-feature obs still play via
\cd{checkpoint.LegacyObsAdapter}, which collapses the one-hot back to the sign at forward time
($\text{sign}=\text{ch}_0-\sum_{k=1}^{3}\text{ch}_k$).

\section{Trunk architectures (\texttt{policy.py})}
The trunk maps \cd{entities} $(B,E,F)$ to per-planet feature tokens $(B,E,h)$ with $h=\cd{HIDDEN}$.
\cd{cfg.ARCH} selects one of two interchangeable trunks; everything downstream (heads, action,
checkpoint format) is identical. The activation in every ResNet-MLP block is \cd{cfg.ACT_FN}
(default \texttt{tanh}).

\subsection{Legacy ResNet-MLP trunk (\texttt{ARCH="trunk"}, the default)}
\begin{verbatim}
  entities (B,E,104)
     -> proj:  Linear(104 -> 512)
     -> [optional] cross-planet single-head self-attention   (USE_ATTENTION, default OFF)
            pre-LN: x = x + attn_o( softmax(QK^T/sqrt h, dead-key masked) V )
     -> [optional] GLU:  x = x + glu_out( glu_val(x) * sigmoid(glu_gate(x)) )   (USE_GLU, ON)
     -> N_RES_BLOCKS x  pre-LN ResNet-MLP block:
            x = x + res_b[i]( act( res_a[i]( LN(x) ) ) )      (N_RES_BLOCKS = 86)
     -> ln_out: LayerNorm(512)
\end{verbatim}
\textbf{Block used:} pre-LayerNorm residual MLP (two $h\times h$ linears with a pointwise activation
between, added back as a skip). At the default width/depth this is the ``\textbf{512$\times$86}''
trunk. With \cd{GRAD_CHECKPOINT} (default \emph{on}) the residual blocks are activation-checkpointed
(recomputed in the backward pass) so the deep stack fits in VRAM.

\textbf{Important:} \cd{USE_ATTENTION} defaults to \emph{False}, so at the shipped defaults the legacy
trunk has \emph{no cross-planet mixing inside the trunk} --- each planet token is processed
independently; planets only interact later, at the masked-mean value pool and the bilinear WHERE head.
The transformer trunk (below) restores per-layer cross-planet attention.

\subsection{Stacked transformer trunk (\texttt{ARCH="transformer"})}
\begin{verbatim}
  entities (B,E,104)
     -> proj:   Linear(104 -> 512)
     -> stem:   N_STEM_RES x pre-LN ResNet-MLP block   (=1, blocks PRE-attention)
     -> stack:  N_TX_LAYERS x TxEncoderLayer           (=6)
     -> head:   N_HEAD_RES x pre-LN ResNet-MLP block   (=4, blocks POST-attention)
     -> ln_out: LayerNorm(512)
\end{verbatim}
So the "pre / post attention" blocks the question asks about are the \textbf{stem} (\cd{N_STEM_RES},
before the encoder stack) and the \textbf{head} (\cd{N_HEAD_RES}, after it) --- both are the same
pre-LN ResNet-MLP block as the legacy trunk. The attention itself lives in \cd{N_TX_LAYERS} encoder
layers.

\paragraph{One \texttt{TxEncoderLayer} (pre-LN encoder block).}
\[
  x \leftarrow x + \mathrm{MHA}\big(\mathrm{LN}_1(x)\big),
  \qquad
  x \leftarrow x + \mathrm{MLP}\big(\mathrm{LN}_2(x)\big).
\]
\begin{itemize}
  \item \textbf{Multi-head attention:} \cd{N_HEADS} heads (head dim $=h/\cd{N_HEADS}$), separate
        \cd{q},\cd{k},\cd{v},\cd{o} linears, computed with
        \cd{F.scaled_dot_product_attention} (flash / mem-efficient). Dead-planet \emph{keys} are
        masked with an additive $-10^9$, matching the legacy single-head mask.
  \item \textbf{MLP:} \cd{mlp_in}: Linear($h\to\cd{TX_MLP_RATIO}\cdot h$), activation,
        \cd{mlp_out}: Linear back to $h$. Default ratio 4 $\Rightarrow$ hidden 2048.
\end{itemize}

\paragraph{Heads-divide-width footgun.} \cd{N_HEADS} must divide \cd{HIDDEN}
(\texttt{assert h \% n\_heads == 0}). The config \emph{defaults} pair \cd{HIDDEN}$=512$ with
\cd{N_HEADS}$=12$, which is \emph{invalid} ($512/12$ is not integer); building a 512-wide transformer
requires overriding \cd{N_HEADS} (e.g.\ 8, head dim 64 --- the value \cd{INVITE_CFG} uses). The
numbers below use 8 heads at width 512.

\section{Heads (shared by both trunks)}
Trunk tokens $\cd{tok}\in\R^{B\times E\times h}$ and a board-globals embedding
$\cd{gp}=\mathrm{relu}(\cd{g_embed}(\cd{globals}))\in\R^{B\times d_g}$ ($d_g=\cd{D_G}=32$) feed all
heads; per planet the head input is $hh=[\cd{tok}\,\Vert\,\cd{gp}]\in\R^{h+d_g}$ ($=544$).

\begin{itemize}
  \item \textbf{WHERE head} (\cd{DEST_HEAD}, default \texttt{bilinear}): pointer scores
        $\cd{dest_logits}[b,s,d]=\langle \cd{dest_q}(hh_s),\,\cd{dest_k}(hh_d)\rangle/\sqrt h$,
        a $(B,E,E)$ source$\times$destination matrix. (\texttt{linear} alternative: one
        Linear($544\to E$).)
  \item \textbf{GATE head:} \cd{gate_head} Linear($544\to1$) $\Rightarrow$ per-source launch logit
        $(B,E)$.
  \item \textbf{VALUE head (critic):} masked-mean pool of \cd{tok} over live planets, concat
        \cd{gp}, then \cd{val_in} Linear($544\to h$) $\to$ \cd{VALUE_RES_BLOCKS} pre-LN ResNet-MLP
        blocks ($=4$) $\to$ \cd{val_out} Linear($h\to1$). Targets are normalized by \textbf{PopArt}
        (output-preserving running mean/var; the head predicts normalized values, raw
        $V=\text{denorm}$).
  \item \textbf{AUX reward head} (optional, \cd{AUX_REWARD_PRED}, default off): a shallow
        \cd{rew_in}$\to$act$\to$\cd{rew_out} off the \emph{same} pooled features, regressing the
        per-step reward $r_t$ as a representation auxiliary. Built only when enabled, so checkpoints
        are byte-identical when off.
\end{itemize}

\section{Action space \& distributions (\texttt{distributions.py})}
The actor is a \textbf{gated per-source allocation}. For every owned source planet it emits a WHERE
distribution over destinations and a launch GATE. \emph{On fire, the planet dispatches its full
garrison routed by the WHERE row; on no-fire it holds.} The action bundle is $(B,E,E{+}1)$:
$[\,{:}E\,]$ is the allocation row, $[\,E\,]$ is fire $\in\{0,1\}$. Log-prob and entropy \emph{sum
over owned sources} (the WHERE term only counts when firing).

\subsection{Destination masking}
WHERE logits are clamped to $\pm\cd{LOGIT_CLAMP}$ ($=8$) and then masked to $-10^9$ on: the diagonal
(self), dead destinations (\cd{alive}$<0.5$), and sun-blocked destinations (\cd{reach}$<0.5$, a
straight shot absorbed by the sun, recovered geometrically in both rollout and update). So the WHERE
support is exactly the legal, reachable targets.

\subsection{The gate (both variants)}
$g=\sigma(\cd{gate_logit})$. \textbf{Train:} $p=g$ (smooth, full-support gradient --- the deadzone
clamp used to zero it and vanish the gate gradient). \textbf{Deploy:} hard deadzone
$p=\mathrm{clip}\!\big((g-\cd{GATE_TRIM_LO})/(\cd{GATE_TRIM_HI}-\cd{GATE_TRIM_LO}),0,1\big)$. Then
$p\leftarrow\mathrm{clip}(p,\cd{GATE_EPS},1-\cd{GATE_EPS})$ and $\text{fire}\sim\text{Bernoulli}(p)$.
The gate is a \emph{logistic} (sigmoid), not a softmax.

\subsection{\texttt{GatedCatDist} --- categorical WHERE (v7 default, \texttt{WHERE\_DIST="categorical"})}
This is where the per-source \textbf{softmax} lives. After masking,
\[
  \cd{lsm}=\log\mathrm{softmax}(\cd{glogits},\,\text{dim}={-}1)\in\R^{B\times E\times E},
\]
a log-probability over destinations \emph{for each source planet}. Then:
\begin{itemize}
  \item \textbf{sample:} dest $\sim$ Categorical(\cd{lsm}); fire $\sim$ Bernoulli($p$). (With
        \cd{GRPO_CRN} the WHERE Gumbel-max noise and the gate uniform are shared across a world-group
        --- common random numbers.)
  \item \textbf{log-prob (per source):}
        $\ell = \underbrace{\text{fire}\log p+(1-\text{fire})\log(1-p)}_{\text{gate}}
        + \text{fire}\cdot \cd{lsm}[\,\text{dest}\,]$, summed over owned sources. (Optionally the
        WHERE term is Rao-Blackwellized over the gate Bernoulli, \cd{GRPO_RB_GATE}.)
  \item \textbf{entropy:} Bernoulli gate entropy $+\;\cd{ENT_DIR_COEF}\cdot p\cdot H_{\text{cat}}$,
        where $H_{\text{cat}}\le\ln E$ is bounded. \cd{ENT_DIR_COEF} defaults to 0, so the bonus is
        \emph{gate-only} (the categorical entropy would blur a BC-sharpened WHERE head).
  \item \textbf{greedy / deploy:} dest $=\arg\max\cd{glogits}$; fire sampled at the trained rate.
\end{itemize}
The bounded-sensitivity $\log\mathrm{softmax}$ log-prob is what makes PPO-after-BC stable.

\subsection{\texttt{GatedAllocDist} --- Dirichlet WHERE (v6 A/B alternative)}
$\alpha=\mathrm{softplus}(\text{logits})\cdot\cd{ALLOC_KAPPA}+10^{-3}$, rows $\sim$
Dirichlet($\alpha$); the full garrison is split across destinations by the sampled simplex. Its
greedy decode uses a \emph{temperature-sharpened} softmax ($\tau=\cd{GREEDY_TAU}=0.5$) over the masked
logits, because the Dirichlet mean spreads the garrison too thin to land a concentrated strike.

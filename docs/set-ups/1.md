

REWARD (replaces the production-shaping reward entirely):
1. win a game is 1000, losing is -1000, and draw is 0
2. win/loss stay FLAT (+/-1000) for the first 100 steps, then decay symmetrically as
   +/-1000 * 0.995^(steps - 100) -- a "flip of winning". Rewards a decisive mid-game without
   making a slow loss cheaper than a fast one in the opening.
3. capture a planet gives +30, losing a planet gives -30
4. the first 50 VALID fleet launches (ones that will land on a planet) get +1 each
5. production milestone: +20 every time the ego's TOTAL ship count (planets + fleets) doubles,
   starting at 100 (100 -> 200 -> 400 -> ...). Monotonic: losing ships never claws reward back.
   (The old "fleet hits a planet" reward is dropped -- it rewarded ship depletion, anti-win.)

ACTION SPACE (v5 target actor, --target-actor 1):
   Per planet the model chooses (a) a DESTINATION planet (categorical over the obs slots) and
   (b) phi = the % of that planet's ships to send (continuous, same as before). A heuristic turns
   the destination into the heading (atan2 straight at it -- the shortest path), so the model never
   has to learn aiming. One launch per planet per step.

CURRICULUM (4-stage, iteration-driven):
stage 1 is against random agent, 100 iteration
stage 2 is against starter, 300 iteration
stage 3 is self-play + starter + random, 1000 iteration

model dim = 512, residual blocks = 6 (target actor makes the task easy enough to go smaller/faster
than the 1024x20 continuous net; tune up if needed)

lr = 1e-4

algorithm: PPO+GAE

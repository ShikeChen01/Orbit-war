# Orbit Wars — Changelog (self-play league lineage)

Covers the **`setup1` GPU self-play–league learner** (the `setup1_*_a100.ipynb` notebooks, now the
`orbit_wars_v12/` package) — a PyTorch reimplementation that trains inside the GPU-batched, Kaggle-exact
`GpuEnv`. Versions were not released as tags: **v8 and v9 shipped together**, and **v10–v12 shipped
together** with the package port, so the per-version deltas below are reconstructed from the code, the
canonical docs (`docs/v12_*.tex`), and the project notes. Newest first.

---

## v9 → v12

Spans **v10** (transformer trunk), **v11** (league monkeypatch cascade), and **v12** (package port +
clean rebuild + per-opponent threat identity + critic-free algorithms + A100 perf). The version that
introduced each item is noted where it is unambiguous.

### Source of truth & docs
- **Python package port (v12).** `orbit_wars_v12/` is now the **single source of truth**; the A100
  notebooks are GENERATED by flattening it with `scripts/make_v12_nb.py` (edit the package → regenerate;
  never hand-edit a notebook). `Config` is a frozen dataclass — the notebooks' module-level globals are gone.
- **v11 league cascade → clean rebuild (v12).** v11 had grown into a monkeypatch cascade of league
  patches; v12 is a one-shot clean rebuild around a single `League` class.
- **Canonical doc set (v12).** Four LaTeX/PDF docs — `v12_setup`, `v12_ppo_gae`, `v12_grpo`, `v12_mcts`;
  the older `arch_v12` / `grpo_v12` / `rl_math_v9` are archived under `docs/archive/`.

### Observation / representation (v12)
- **Per-opponent threat identity.** Inbound-fleet (threat) ownership changed from a single self/enemy
  **SIGN** (3 features/fleet: sign + eta + log-ships) to a **4-channel ego-relative seat one-hot**
  (6 features/fleet: 4 owner channels + eta + ships). **`F_DIM` 104 → 194.** (v9 fixed 4p
  opponent-collapse for *body* ownership; v12 extends the fix to *threat fleets*.)
- **Raw per-planet ships.** The body garrison (`b6`) and inbound-fleet sizes (`slg`) are now **RAW
  integer counts** — the `ship_log_t` compression was removed; the *global* ship aggregates and the
  `Φ_ship` shaping potential stay log-compressed (raw per-planet, log global).
- **Motion-aware threat targeting.** `fleet_target_batch` now **leads moving targets** via a swept
  relative-velocity quadratic (planet velocity = one-step finite difference), fixing comet/orbiting
  threats; plus an **apparent-vs-sun-aware** target so a sun-bound fleet still appears in the threat list
  of the planet it is aimed at.
- **Threat selection.** "15 soonest + 15 biggest" → **top-30 inbound fleets by size**.
- `LegacyObsAdapter` down-converts the current 194-d obs to 104 / 101 so pre-v12 league members still play.

### Network / architecture
- **Transformer trunk (v10).** Stacked pre-LN encoder layers (param-matched ≈1.04× to 512×32), adaptive
  entropy annealing, teacher-KL. (Cross-planet attention existed in v9 but was *off* in the learner.)
- **`ARCH` selector (v12).** `"trunk"` (legacy ResNet-MLP) | `"transformer"` (stack) | `"blockseq"`
  (arbitrary ordered `res`/`attn`/`seq` sequence parsed from `TRUNK_SPEC`).
- **Auxiliary heads (v12).** Optional UNREAL **reward-prediction** head and a **win-bet** head (bet on the
  eventual outcome) — pure representation auxiliaries off the shared trunk; both default OFF.
- **Grad checkpointing (v12).** Activation-checkpoints the deep trunk (the 512×86 OOM fix).

### Learning algorithm (v12)
- **Critic-free alternatives to PPO+GAE.** `cfg.ALGO`: `"ppo"` (shipped default, learned PopArt critic) |
  `"grpo"` (group-relative baseline, no critic) | `"mc"` (discounted Monte-Carlo return-to-go). PPO and
  GRPO share the same net, so weights are interchangeable.
- **GRPO variance-reduction & anti-collapse.** A family of flagged advantage estimators (rank / CVaR /
  sibling / Dr.GRPO, clip-higher, Rao-Blackwellized gate, …), **all default-OFF** — the battle-tested
  legacy per-group std-norm is the keeper (the "anti-collapse" estimators empirically drove passivity).
- **MCTS proof of concept.** `mcts.py`: AlphaZero-style PUCT (net prior + bounded heuristic leaf,
  snapshot/restore of `GpuEnv`, fixed scripted opponent), with a step-scheduled deploy time budget.

### Reward (v12)
- **Default reverted to the legacy dense channels.** `USE_POTENTIAL_SHAPING=False` so the terminal W/L
  (±`WIN_BONUS`) dominates the return; policy-invariant potential-based shaping is now opt-in.
- **Asymmetric "lose-slower" decay.** `WIN_DECAY=1.0`, `LOSS_DECAY=0.9995`. (An earlier claim that this
  decay caused the GRPO passivity collapse was investigated and **retracted** — the cause was the
  advantage-estimator changes, not the decay.)
- **`DENSE_REWARD_SCALE`** attenuator on the capture + production-milestone channels (the launch-shaping
  channel is exempt — it is the anti-passivity activity floor).

### League / curriculum (v12)
- **Measured eviction.** `evict_mastered` removes any league member the learner has mastered under one
  standard (2p seat-averaged score > 0.90 OR 4p first-place rate > 0.75) — scripted anchors **and** neural
  snapshots/invited members alike; protects the self-anchors, the newest snapshot, and the random/greedy
  watchdogs. Runs at start and on every recalibration.
- **Dormant calibration watchdogs.** `random`/`greedy` re-enter as live opponents if the learner
  underperforms its own rating prediction (a collapse alarm).
- **2p:4p mix pinned to 3:1** (`share_4p` baked to 0.25).

### Anti positional-overfit (v12)
- **Deterministic exhaustive seat-swap.** Each world is tiled P-fold with a per-block board rotation
  (2p {0,180}°, 4p {0,90,180,270}°), so the fixed ego plays every seat's geometry in one batch — fixing
  the seat-0 positional overfit (v9's *random* rotation augmentation was not enough).

### A100 performance (v12)
- `torch.compile` on the learner forward, **fused Adam**, TF32 matmul, **GPU-side stat accumulators**
  (one `.item()` flush per update instead of per-minibatch), grad checkpointing, and **no per-step CUDA
  sync** in the rollout (finished envs masked, no early-break).
- **Latest:** `settle_n` computed once/step and vectorized; `env_encode` refactored to a pure-tensor
  `_encode_core` and `torch.compile`d (fuses the launch-bound rollout encode).

### Notebooks (latest v12)
- **deep** (155-block, 22.7M) vs **lean** (30-block, 5.0M) h=256 `blockseq` notebooks for side-by-side
  training, plus a **critical-step MCTS** deploy schedule (deep search on a few early turns, greedy elsewhere).

## v8 → v9

### Observation / representation
- **Per-body ownership: scalar → 4-channel ego-relative seat one-hot** — `[self, enemy+1, +2, +3]`,
  neutral all-zero. Lets the policy tell **which** opponent owns a planet in 4p (the v8 scalar collapsed
  all opponents into one value). **`F_DIM` 101 → 104** (body features 11 → 14). `LegacyObsAdapter`
  down-converts v7/v8 (101-d, scalar-owner) members so they still play in the v9 build.
- (Threat-fleet ownership remained a single self/enemy SIGN in v9 — that became the 4-channel one-hot in v12.)

### League / Elo stabilization (v9.1–v9.6)
v8 introduced the **mixed 2p/4p dual-Elo league** with invited members; v9 stabilized it:
- **Rolling self-anchor.** The learner's Elo is grounded on its own frozen high-water snapshot rather than
  on saturated scripted anchors — fixing an Elo-saturation ceiling that pinned ratings.
- **Scripted-exposure caps.** `SCRIPT_SHARE_CAP` (scripts ≤ 30% of matches while any neural member carries
  weight) and `MAX_SCRIPT_SEATS_4P` (≤ 1 scripted seat per 4p game).
- **Measured (not copied) anchor ratings.** 4p anchor Elo and invited-member ratings are measured on
  held-out worlds instead of being 2p-copied or carried as stale stamps.
- **Cheap learner-only recalibration** (`LEARNER_RECAL_EVERY`, blended into the live ratings) plus 4p-Elo
  noise control.

### Network
- No trunk change — v8 and v9 are both the MLP/ResNet trunk lineage (cross-planet attention was coded but
  left OFF in the v9 learner; the transformer trunk arrived in v10).
